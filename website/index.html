Compatible uses

Built for LAN games. Useful beyond them.

OrbitLan is a simple, open-source Hamachi alternative for small Windows groups and software that supports LAN multiplayer or direct-IP connections: Minecraft Java servers and Direct Connection, classics such as Need for Speed: Most Wanted and Battlefield 1942, plus many other compatible games.

Development servers and private IP-based tools can use the same virtual network too. Automatic game discovery and firewall behavior vary, so direct IP is the most dependable option when a title supports it.

Game names are compatibility examples only. OrbitLan is not affiliated with or endorsed by their publishers.
