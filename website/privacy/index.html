Privacy · plain language

What OrbitLan handles.

OrbitLan does not require an account. A small amount of temporary connection information is still needed to form a virtual LAN.

Updated September 27, 2026

The website

The OrbitLan website does not currently set its own analytics or advertising cookies, and it does not include a login form. It is served through Cloudflare, which necessarily processes ordinary request information such as your IP address, requested URL, user agent, and security signals under Cloudflare's own policies.

The public coordinator

When you create or join a room on the public service, the coordinator processes the room code, a generated peer identifier, your chosen display name, edition, assigned virtual IP address, host state, and connection-signaling messages. New clients also send a member token; the coordinator stores only its SHA-256 hash for room actions such as leaving or removing a node.

Room membership and signaling state are ephemeral. A node that stops checking in is removed after about 60 seconds, and an empty room is reset. OrbitLan does not create a permanent user profile or room history.

Network traffic

Your application and game frames are encrypted by the OrbitLan clients and are not carried by the coordinator endpoint. Peers normally exchange them directly. If direct connectivity fails and relay is enabled, a TURN relay forwards ciphertext and can observe network metadata such as addresses, timing, and volume. In the current v1 design, traffic keys derive from the room code sent to the coordinator, so this encryption protects data in transit but is not protection from a service operator able to combine coordinator data with captured relay traffic.

Peers are not anonymous to one another. Direct peer-to-peer connection setup can reveal public network addresses to other members of the room. Only share a room code with people you trust.

On your device

The Windows and Linux clients keep operational settings locally, including the coordinator address, relay preference, display name, and a generated member token. OrbitLan needs operating-system network privileges to create and use its virtual adapter. Uninstalling the application does not control copies of logs or configuration you may have separately created or backed up.

External services

GitHub hosts the source code and Community downloads. Patreon hosts the Supporter download. Following those links is subject to the privacy terms of the relevant service. If you self-host OrbitLan, your chosen coordinator and relay operator control their own infrastructure and retention practices instead of OrbitLan's public service.

Questions

This page describes the current project's behavior in plain language and is not a substitute for the policies of Cloudflare, GitHub, Patreon, or a self-hosted operator. For a privacy question, email furqanshaheer@gmail.com or open a GitHub issue without posting private room information.
