About the project

A small virtual LAN made for real game nights.

OrbitLan is an independent open-source project created by Furqan Ahmed for connecting trusted Windows and Linux devices.

Official project information · Updated September 27, 2026

What OrbitLan is

OrbitLan creates a private virtual local network over the internet. Each node receives a 10.69.0.x address, and compatible games, development servers, and IP-based tools can communicate as though the devices were on one local network.

The Windows client provides a graphical interface, automatic adapter setup, and notification-area mode. The preview Linux client provides terminal commands and a systemd service for desktops, servers, WSL2, and cloud VMs. Both use the same room codes and networking protocol.

Why it exists

Furqan built OrbitLan in his free time after not making something just for fun in a while. The original goal was a simple way to play older games such as Need for Speed: Most Wanted and Battlefield 1942 with friends again, without requiring everyone to manage a complicated network dashboard.

That same virtual LAN can also connect a Minecraft server, a development service, or another private IP-based tool. OrbitLan is not a general-purpose privacy VPN and does not change the public location of normal web traffic.
