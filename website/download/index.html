Community and Supporter

Community Edition is free and published on GitHub. On OrbitLan's hosted coordinator it can host five computers total: the host plus four others. Self-hosted coordinators can remove that edition limit.

The one-time $5 Supporter download contains the Windows installer, Windows portable build, and Linux builds together. It adds larger hosted rooms, Force Relay, and the Supporter visual theme; the encryption and network core remain the same.

Install safely

  1. Download only from this page, the official GitHub repository, or the official Patreon product.
  2. Compare the SHA-256 file beside a release asset when you need to verify an exact download.
  3. On Windows, approve the installer once so it can add the virtual adapter and background network service.
  4. On Linux, read the included README before running sudo ./install.sh or starting a room directly.
Windows and Linux are interoperable. A Linux server or VM can join a room created in the Windows app, and Windows nodes can reach its 10.69.0.x address without exposing the service publicly.
