OrbitLan guide

A simple open-source Hamachi alternative

OrbitLan is a small, account-free virtual LAN for trusted Windows and Linux groups that want to play compatible LAN games or connect private IP-based tools.

Written by Furqan Ahmed · Updated September 26, 2026

If you need a Hamachi-style network for a game night rather than a large managed VPN platform, OrbitLan focuses on a short flow: one person creates a room, shares a six-digit code, and everyone receives an address on the same private subnet.

The project is MIT licensed and its complete source is public. There is no account inside the app. Direct peer-to-peer links are attempted first, game traffic is encrypted between peers, and an optional relay can keep a group connected when restrictive networks prevent a direct path.

Where OrbitLan fits

  • Compatible LAN and direct-IP games: useful for small groups playing Minecraft Java, older PC games, and other software that accepts private IP connections.
  • No app account: joining is based on a temporary room code rather than a hosted user profile.
  • Open source and self-hostable: inspect, build, or run the coordinator yourself under the MIT license.
  • Direct-first networking: peers connect to each other when the network allows it, with encrypted relay fallback in Auto mode.
  • Windows app and Linux terminal client: use the native notification-area app on Windows or the lightweight headless preview on Linux.

Important limits

OrbitLan has a stable 64-bit client for Windows 10 and Windows 11 plus preview Linux builds for amd64 and arm64. The Linux version is headless and requires TUN support; macOS, phones, and consoles are not supported. On OrbitLan's public service, the free Community build can host five computers total—the host plus four others. Community users can still join a larger room hosted by Supporter Edition. Self-hosted coordinators can remove the edition limit and use an operator-chosen room cap.

It is a private virtual LAN, not a general-purpose privacy VPN. It does not hide ordinary web browsing, change your public location, or guarantee that every LAN game will work. Game discovery and firewall behavior differ by title, so direct IP remains the safest connection method when available.

Security starts with the room code. Treat it like a temporary password and share it only with people you trust. The coordinator can observe connection metadata, but game frames are encrypted between peers.

How to try it

  1. Download Community Edition from the official download page and install the appropriate Windows or Linux build on each computer.
  2. Create or join a room with the six-digit code. The app shows connected nodes and their private OrbitLan IP addresses.
  3. Open the game's LAN mode or enter the host's OrbitLan IP in its direct-connect screen.
  4. Check the firewall if needed. Allow the game on private networks; do not disable Windows Firewall wholesale.

Community Edition includes the same networking core and encryption as Supporter Edition. The $5 Supporter build adds larger hosted rooms, a Force Relay troubleshooting option, and its own visual theme. Both editions remain buildable from the public source.
